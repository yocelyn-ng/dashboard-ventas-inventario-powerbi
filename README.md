# 📊 Dashboard de Ventas e Inventario en Power BI

## 📌 Descripción

Proyecto de análisis de datos desarrollado en Power BI para estudiar el comportamiento de las ventas y monitorear los niveles de inventario.

El dashboard permite analizar información por tienda, categoría y producto, visualizar la evolución temporal de las ventas e identificar productos que presentan niveles bajos de stock.

## 🎯 Objetivo

Desarrollar un dashboard interactivo que permita transformar datos de ventas e inventario en información útil para apoyar la toma de decisiones.

## 🛠️ Herramientas utilizadas

- Power BI Desktop
- Power Query
- DAX
- Excel
- CSV

## 🔄 Proceso de desarrollo

1. Importación de las fuentes de datos.
2. Limpieza y transformación de información.
3. Construcción del modelo de datos.
4. Creación de relaciones entre tablas.
5. Desarrollo de medidas DAX.
6. Creación de indicadores KPI.
7. Diseño de visualizaciones.
8. Implementación de filtros y navegación.
9. Incorporación de drill-through para análisis detallado.

## 📈 Indicadores principales

El dashboard permite analizar:

- Ventas totales.
- Unidades vendidas.
- Productos con stock bajo.
- Ventas por tienda.
- Ventas por categoría.
- Ventas por producto.
- Evolución temporal de las ventas.

## ⚙️ Funcionalidades

El reporte incorpora:

- Segmentadores interactivos.
- Navegación entre páginas.
- Drill-through por producto.
- Formato condicional.
- KPIs.
- Análisis temporal de ventas.
